Fim do contrato e saída da pessoa

O que acontece quando um escritório deixa de ser cliente e quando uma pessoa perde o último acesso: no Console (encerrar, ficha encerrada, reabrir, carteira, histórico, Equipe T3jus e Suporte) e no Portal (aviso, só leitura, Equipe e a tela depois de entrar). Os prazos são os aprovados no inventário de dados; o desenho só mostra o que acontece e quando. Cada estado tem computador (1440) e celular (412); clique numa imagem para abrir o HTML naquele estado. Decisões, servidor e perguntas estão em NOTAS.md.

  1. 19/11/2026Fim do contrato. Portal só leitura.
  2. até 18/1230 dias só para consulta e para baixar os dados.
  3. 19/12/2026Só o acesso fecha. Nada é apagado; dá para pedir uma cópia.
  4. 19/03/2027E-mail e senha de quem só tinha este escritório.
  5. 18/06/2027Registros de entrada (6 meses).
  6. 19/11/2031Fim da guarda: dados dos clientes, cadastro, notas, documentos e histórico. Até aqui, dá para reabrir.

1. Console · encerrar o contrato

ficha.html, aba “Contrato e documentos”. A ação fica no pé da folha Estágio, que ganha o terceiro passo, Encerrado. Só a Administração vê o botão.

Cliente ativo, com a ação de encerrar

O trajeto passa a ter três passos (Em implantação, Ativo, Encerrado). Embaixo, separada por um fio, a linha “Encerrar o contrato”, que diz logo que nada é apagado: 30 dias só para consulta e os dados guardados 5 anos. Botão de perigo, de contorno.

Abrir: ficha.html?aba=contrato&estado=fc-ver (estreite a janela para ver o celular)

Sem permissão (Implantação)

Rafael, da Implantação, vê a linha sem o botão e o motivo: “Quem encerra o contrato é a Administração.” Financeiro e Suporte veem o mesmo.

Abrir: ficha.html?aba=contrato&estado=fc-ver&papel=implantacao (estreite a janela para ver o celular)

Janela de encerrar

alertdialog largo. À esquerda, o que acontece e quando, com as datas calculadas da data do fim (só leitura, 30 dias para baixar, acesso fecha sem apagar dados, e-mail e senha em 90 dias, o que fica guardado 5 anos, inclusive os dados dos clientes). À direita, a data, o motivo obrigatório e a confirmação forte: escrever o nome do escritório, com “O nome confere”. Foco começa no Cancelar.

Abrir: ficha.html?aba=contrato&estado=fc-encerrar (estreite a janela para ver o celular)

Erros

Data antes de hoje, motivo vazio e nome que não confere: resumo no topo (“Falta acertar 3 pontos… O contrato não foi encerrado.”), erro preso a cada campo, foco no primeiro. O botão nunca fica desabilitado.

Abrir: ficha.html?aba=contrato&estado=fc-encerrar-erros (estreite a janela para ver o celular)

Enviando

Campos travados, botão “Encerrando…” com aria-busy e aviso para leitor de tela.

Abrir: ficha.html?aba=contrato&estado=fc-encerrar-enviando (estreite a janela para ver o celular)

Falha do servidor

Nada mudou, o contrato continua ativo e o que foi escrito continua na janela. “Tentar de novo” e o código para o suporte técnico.

Abrir: ficha.html?aba=contrato&estado=fc-encerrar-falha (estreite a janela para ver o celular)

Conflito de versão

Rafael Teles mudou o cliente enquanto a janela estava aberta: o aviso diz quem e a que horas, compara o que mudou e oferece “Fechar e conferir” (foco) ou “Encerrar mesmo assim”. Nada foi encerrado.

Abrir: ficha.html?aba=contrato&estado=fc-encerrar-conflito (estreite a janela para ver o celular)
